Welcome. In this course you build **DevBlog**, a headless CMS and public blog, from an empty repo to a running `docker compose up` stack — Node/NestJS + MongoDB + code-first GraphQL on the back end, Next.js (App Router) with SSR/ISR on the front end, and an admin UI for publishing and moderation tying it together.

## In this module

- [Overview](/devblog/en/introduction/overview/) — what DevBlog is, the feature list, and the map from each module to the Learn Hub course it adapts.
- [Architecture](/devblog/en/introduction/architecture/) — the system design, the request and content paths, and why each part of the stack was chosen.
- [Prerequisites](/devblog/en/introduction/prerequisites/) — the tools to install on macOS, with verification commands.
- [Roadmap](/devblog/en/introduction/roadmap/) — the Real-World Projects series and where DevBlog fits.
