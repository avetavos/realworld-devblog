ยินดีต้อนรับ ในคอร์สนี้คุณจะได้สร้าง **DevBlog** ระบบ headless CMS พร้อมบล็อกสาธารณะ ตั้งแต่ repo เปล่า ๆ ไปจนถึงสแตกที่รันได้ด้วย `docker compose up` — ฝั่งหลังใช้ Node/NestJS + MongoDB + code-first GraphQL ฝั่งหน้าใช้ Next.js (App Router) พร้อม SSR/ISR และมีหน้า admin สำหรับเผยแพร่และตรวจสอบเนื้อหาเชื่อมทุกอย่างเข้าด้วยกัน

## ในโมดูลนี้

- [Architecture](/devblog/th/introduction/architecture/) — การออกแบบระบบ เส้นทางของ request และเนื้อหา และเหตุผลที่เลือกแต่ละส่วนของสแตก
- [Prerequisites](/devblog/th/introduction/prerequisites/) — เครื่องมือที่ต้องติดตั้งบน macOS พร้อมคำสั่งตรวจสอบ
- [Roadmap](/devblog/th/introduction/roadmap/) — ซีรีส์ Real-World Projects และตำแหน่งของ DevBlog ในซีรีส์นี้
